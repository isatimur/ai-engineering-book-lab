# Evidence Packs

Evidence packs sit between notes and prose.

They gather:
- source cluster
- strongest claims
- tensions / objections
- notable quotes
- chapter relevance

## Registries

- `External References.md` — written sources the book engages with directly
  (papers, texts), each with a stated relation to chapters.
- `Shared Artifacts.md` — repos/papers/resources speakers shipped alongside
  corpus talks, auto-extracted from full video descriptions
  (`99_Meta/video-descriptions.jsonl`); regenerate after major ingests.
