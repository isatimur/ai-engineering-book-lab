# Vibe Coding with Confidence — Itamar Friedman, Qodo

## Summary
Itamar Friedman (CEO, Qodo) frames three generations of AI coding tools - Gen 1.0 autocomplete, Gen 2.0 agentic chat, and an emerging Gen 3.0 built on CLI-driven, multi-agent workflows spanning the full SDLC (not just code generation but review, testing, refactoring) - and argues the real "game changer" is holistic, workflow-level integration rather than another single-task tool. He cites Karpathy's public reversal from evangelizing "vibe coding" to emphasizing context and multi-step workflows for code he "cares about," and argues that generation-only tools work for greenfield projects but fail on large existing codebases where maintainability, testing, and review dominate. He live-demos a newly soft-launched Qodo CLI tool that can generate new specialized agents on demand (e.g., a "merge review" agent), chains agents via piped tool calls, and describes an early attempt at agent-to-agent (A2A) communication, noting an informal audience poll found only one attendee reporting they use A2A. He references existing Qodo products - Qodo Cover (an open-source automated test-coverage tool) and Qodo Merge (a code-review tool) - as the "shift-left" pieces feeding best practices into the new agent workflow, and predicts a near-term future of specialized agent "swarms."

## Why it matters
- Documents a live vendor demo of an agentic CLI (creating agents on demand, piping agents together, early A2A experimentation) as evidence of where multi-agent developer tooling stood at the time.
- Captures Karpathy's own public walk-back of "vibe coding" as a first-person data point on the industry's shift toward context-rich, workflow-based AI coding.
- Gives a concrete adoption signal (informal audience poll: about one of dozens using A2A) useful for calibrating claims about agent-to-agent protocol maturity.
