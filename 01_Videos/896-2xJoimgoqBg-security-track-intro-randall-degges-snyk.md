# Security Track Intro — Randall Degges, Snyk

## Summary
Randall Degges of Snyk has been a developer and security professional for most of his life. In this short keynote slot he frames the state of AI security and invites the audience to the first security track at the World's Fair, which he emcees all day. It is a framing talk, not a technical one, but it sets out the problem map the track's later talks address.

**What excites him**
Generative AI lets people build better software faster and ship it to real users. He calls it almost "a cheat code". The question is what stops everyone in the room from doing this at scale.

**Obstacle 1: insecure generated code**
AI-generated code can contain security issues. Degges treats this as old news and not a big deal: humans write insecure code too, so security is already a core part of the modern development life cycle. The answer is the same for both.

**Obstacle 2: autonomous agents in production**
The harder and more interesting problem is deploying autonomous agents so you can sleep at night, without fearing they go off the rails, do what they should not, or harm the business or its users. He calls this "a much more difficult problem" than insecure code.

**Obstacle 3: geopolitics**
Model access itself is now a security matter. He polls the room on frustration at losing access to one model and at not yet being able to use a new OpenAI release, and ties both to security.

**The goal**
The biggest open problem, in his framing, is using AI "fearlessly" and having it be "secure by default". The track features speakers from NVIDIA, Anthropic, Keycard and Snyk.

## Why it matters
- Gives a compact three-part map of AI security: insecure generated code, runaway autonomous agents, and geopolitical limits on model access.
- Separates the solved-in-principle problem (scan generated code like human code) from the open one (governing autonomous agents in production).
- Frames model availability as a security and supply-chain concern, not only a product one.
- Works as the opening frame for the security-track talks from Snyk and others in this corpus.
