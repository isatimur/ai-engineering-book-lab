  • models — JudgeDim, JudgeScore, JudgeInput contract
  • model_factory — cost-aware routing across providers
  • pricing — per-model cost estimation
  • retry — backoff tuned for judge calls
github.com/isatimur/mash-core
Control plane

Bounded missions, not open-ended agents

  1. 01 corpus-sync agent Skill
  2. 02 chapter-explainer-video agent Skill
  3. 03 book_autoresearch.md program
  4. 04 source_anchoring_pass.md program

Every pass takes a specific mission ("anchor claims 16–19"), runs to completion, commits its result, logs the pass — reversible and auditable in git.
